Bandarlog visual assets

- monkey.webp: original mascot generated for this project and optimized as WebP with transparency. The reference mockup is not embedded in the interface.
- icon.svg and raster icons: original vector artwork created for Bandarlog.
- Interface icons: Lucide, ISC license, provided by lucide-react.
- Nunito Sans: SIL Open Font License, bundled locally through @fontsource/nunito-sans.

- brand-mark.webp / brand-mark.png: original monkey logo with the green square background removed, transparent alpha.
- monkey-vine.webp: original 3D mascot in a vine-swinging pose, generated for the completion animation, transparent alpha.
