Bandarlog visual assets

- monkey.webp: original mascot generated for this project and optimized as WebP with transparency. The reference mockup is not embedded in the interface.
- icon.svg and raster icons: original vector artwork created for Bandarlog.
- Interface icons: Lucide, ISC license, provided by lucide-react.
- Nunito Sans: SIL Open Font License, bundled locally through @fontsource/nunito-sans.

- brand-mark.webp / brand-mark.png: original monkey logo with the green square background removed, transparent alpha.
- monkey-vine.webp: historical 3D source, preserved for compatibility; no longer rendered by the interface.

- artwork/mascots: original high quality 3D scout mascot illustrations generated for Bandarlog, in transparent six-character atlases. Each cell depicts a distinct activity, pose and props. Historical originals preserved; static 3D mascots are no longer rendered or requested by the interface.
- artwork/icons: paired vector pictograms composed from Lucide (ISC) with Bandarlog green/gold styling. Rebuild with `node --import tsx scripts/build-artwork-icons.ts`.

- monkey-vine-2d.webp: new original flat 2D monkey swinging from a vine, generated from the official brand-mark reference for the approved task-completion animation. Source: generated_images/exec-0a3ea63d-5d9d-45ab-9c31-fc406cbec39b.png; optimized to transparent 569×650 WebP. Direction: preserve the logo's brown/cream face, oval eyes, round ears, tuft and smile, full small body and tail, one hand holding a green vine, simple green neckerchief; isolated 2D cartoon, no 3D, scenery, text or watermark. Original generation remains in the task workspace.
