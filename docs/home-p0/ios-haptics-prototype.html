Ensayo de interruptor nativo

Prototipo técnico independiente. No modifica tareas ni preferencias de Bandarlog, ni llama a una API.

Acción real: toca el control con el dedo. Comprueba si hay feedback del sistema en Safari y después en una PWA instalada, anotando dispositivo, versión, ajustes hápticos y resultado.

No se oculta otro control ni se invocan eventos sintéticos. Un resultado visual correcto no demuestra que haya vibración.
